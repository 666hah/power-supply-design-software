# Buck / Boost：计算、闭环仿真与对比报告

三个可配置行为原型：TPS40200 参考 Buck 电压模式、LTC3864 参考 Buck 峰值电流模式、LM5022 参考 Boost 峰值电流模式。按本次需求，不接入独立原厂模型验证流程。它们用于统一设计计算与开关仿真，不等同于三款芯片的完整硅模型。

## 使用入口

使用一体成型等外购电感时，可在主界面取消“启用电感磁芯与绕组设计”，保留 L 并填写成品 DCR。此模式的主界面 DCR 同时用于计算和导出，优先于控制器窗口中的自制电感 DCR 覆盖。额定电流初筛、附加损耗边界与两端报告见 [成品电感说明](PURCHASED_INDUCTORS.md)。

桌面 File 菜单和网页版“示例”中增加三个 24W 示例，保留原有三路正激、三路 CCM 反激和 QR 反激。Buck 两种模式采用 18–30V→12V/24W；Boost 采用 9–18V→24V/24W。为方便运行与教学，示例频率取 50kHz，L=47µH。当前示例已填入真实器件参考参数，逐颗电容与成品电感 DCR 以随附 JSON 为准；早期示例的 30mΩ DCR 不再代表现行器件。选型依据见 [示例器件初选](EXAMPLE_REAL_PARTS.md)。

1. 加载示例，选择 Vinmin 或 Vinmax 查看计算波形和环路。
2. 打开“LTspice 电源闭环 · 配置与导出”（网页版在“报告与检查”）。原型必须与拓扑、控制模式匹配。
3. 可修改频率、占空比、消隐、最小脉宽、采样滤波、斜坡、软启动及通用故障处理。按“应用到计算器”后重新计算；保存 JSON 会保留这些配置。
4. “导出 ASC 工程”生成可直接打开的电路工程 ZIP；“运行并导出对比报告”实际调用本机 LTspice，输出 Word 和同名证据 ZIP。运行任务支持后台执行、取消和每工况超时。

独立工程沿用兼容文件名 `Flyback.asc` / `Flyback.cir`，图内实际为 Buck 或 Boost，**没有变压器**。硬件在输入两端保持相同；所有数值入口在 `design_params.inc`。

## 先分清两种导出

- **导出 ASC 工程**：只生成工程 ZIP，不启动 LTspice；解压后打开 `Flyback.asc`。
- **运行并导出对比报告**：先运行 Vinmin/Vinmax 瞬态，再做启用的实际 FRA 和半幅复核；Word 与同名 ZIP 是最终交付。全部瞬态超时意味着只有诊断报告，没有有效波形与对比结论。

已加载示例时无需再点“填入参考值”。该按钮现在只替换控制器特征，保留电感 DCR、软启动、补偿与测试设置；“恢复全部默认”才会整体重置。修改原型或硬件之后，应先应用并重新检查环路整定。

对于 18–30 V → 12 V / 24 W、50 kHz 的 Buck 电压模式，先以目标 fc=2 kHz、PM=60°、三型补偿开始验证。推荐测试起点：软启动 1 ms、30 ms 负载阶跃、40 ms 结束、1 线程、每瞬态工况超时 300 s；FRA 1–4 kHz、每倍频程 3 点、最少 100 周期、注入峰峰值 2%（程序另作 1% 半幅复核）。这些是此示例的测试设置，不能保证任意电源参数都在此时间内达到稳态。

2026-10-29 用户的 4 kHz / 75 ms 工程在两个端点均超过 600 s；改为 1 线程仍很慢。不能把此失败简单归因为线程数，也不能从失败报告认定实际电路不稳定。另存的推荐配置保留用户硬件和自动 DCR，仅明确改变补偿目标与测试日程。详见 `output/Buck_导出验证_20261029/`。

## 功率级如何计算

新原型启用物理周期模型。每颗并联电容都有独立的 C、ESR 状态；零 ESR 支路使用公共理想电压状态，不人为加入很小 ESR。负载为电阻，输出防反管采用固定压降。

每一开关区间建立仿射状态方程 `dx/dt = A·x + b`，状态包括电感电流与电容内部电压。用矩阵指数传播，联立周期重复条件 `x(T)=x(0)` 和反馈前电压周期均值目标，求占空比。电流下降至零时切入 DCM 空闲区，禁止非同步电路出现持续负电感电流。

Buck 的导通区包含 Vin、开关 Ron、采样电阻、L/DCR 和输出；续流区包含续流二极管压降、L/DCR 和输出。Boost 导通区为 Vin→L→MOS→采样电阻，关断区经二极管向输出电容及负载供电。仿真二极管的导通斜率固定为 1mΩ；没有将用户已取消的“动态电阻”重新作为必填输入。

预设效率仍可用于原有预设计；进入此物理周期模型后不再作为额外压降重复叠加。最终损耗、磁芯和开关损耗估算仍由计算器损耗模块提供；SPICE 线性电感不自动包含这些全部损耗，效率数字不可视为完全同口径。

DCR 默认由冻结的匝数、MLT、线径与电阻率得到。设置为非负值时是明确的实测／选型覆盖，同时进入计算波形、磁件直流铜阻信息和 SPICE；输入两端不重新换一颗电感。

## 调制域必须分清

| 原型 | 比较器 | 反馈基准 | 管脚域说明 |
|---|---|---|---|
| TPS40200 参考 | 电压锯齿与补偿输出比较 | 0.7V | 锯齿默认幅值为输入母线的 0.1 倍，两端输入分别更新 |
| LTC3864 参考 | 高侧真实采样电流×Rs＋斜坡 | 0.8V | ITH 零电流偏置 0.8V；ITH→CS 默认斜率 0.05V/V 为可配置近似，非原厂保证值 |
| LM5022 参考 | 低侧采样电流×Rs＋斜坡 | 1.25V | 比较器等效指令约为 (COMP−1.4V)/3；默认 0.5V 限流也包含斜坡 |

`comp` 是统一的比较器指令域；`comp_pin` 是按原型偏置／比例换算的 COMP 或 ITH 显示量。`u = k·(Vpin−Voffset)`。这两个量不能混当，也不能用限流阈值代替采样增益。参考原型的采样增益为 1，芯片引脚转换另行记录。

补偿器仍为软件的二／三型传递函数行为实现，不是芯片 gm、输出阻抗、饱和摆幅和补偿引脚寄生的完整模型。实际设计时应核对管脚电压是否落在数据手册范围，特别是可修改的 LTC3864 ITH 映射。

自动斜坡：LTC3864 参考采用输出侧下降电流斜率的 0.75 倍作为工程起点；这不是其内部斜坡的测量值。LM5022 参考采用 `45µA·fs·(2kΩ+外部CS滤波串阻)`。手动模式允许覆盖，计算和仿真使用同一来源；自动整定不能替代周期二检查。

## 环路与报告

在“按规格生成初版（Buck / Boost）”里选择 Boost，可以用 LM5022 峰值电流参考模型生成成品 L、DCR、输入和输出电容组、采样电阻、CS 附加串阻和二型补偿。两端输入复用这套硬件。若预估电感伏秒的最大位置在区间内，再增加该电压的满载校核。计算与导出使用同一组 Rs、斜坡、频率和控制参数。

对 LM5022 的普通运放补偿电路，环路页 KP 表示从输出电压扰动到 CS 等效指令的增益系数。实际 COMP 引脚的系数为三倍，阻容反算写回时再除以三。Word 和 Excel 报告均使用这次换算。模型按每个 CCM 工作点的 RHP 零点筛选初版交越频率。详细公式、限流容差及 24 W 例程见《自动计算参数依据》第 4–6 章。[自动计算参数依据](reference/自动计算参数依据.docx)

对同一周期映射求状态和占空比微分；峰值电流模式同时线性化“峰值采样＋斜坡＝指令”的关断条件。联立后形成周期内环，再用双线性变换得到低频连续等效。Boost CCM 的非最小相位行为由物理模型保留。

计算线性化不包含消隐、传播延时、器件非线性电容、ESL、二极管反向恢复、芯片轻载跳脉冲和所有保护状态。当前仅在稳定 CCM 输出该环路；DCM 仍可计算工作点及波形，不冒充固定频率 CCM Bode。

完整比较报告包含：

- Vinmin/Vinmax 的独立工况、控制参数及模型边界。
- 启动和负载阶跃、软启动及故障电平。
- 完整周期的电感 RMS/峰值/平均值和 D1 续流／整流电流对比。
- 输出、防反管前电容端电压、输出纹波及器件反压。
- 逐周期脉宽与峰值重复性、阶跃前长窗口漂移检查。
- 实际开关闭环 FRA，功率级与补偿器分别对比，以及同频点半幅注入复核。
- 原始电路、参数、日志、FRA 复数数据和 `comparison.json`，便于复查差异。

单路 Buck/Boost 不做多路交叉调整率；报告明确“不适用”，不会编造角点。原有输入两端 Excel／Word 模块报告仍可直接导出。

## 速度与边沿精度

单个电源的默认“快速闭环”关闭极快的 Coss、Cj、等效门电容，但保留 L、DCR、C/ESR、Ron、固定压降、采样及控制延时。适合其已验证工况的电流包络、输出纹波、环路和负载动态比较；**不能用于结电容尖峰、反向恢复、ZVS 或动态开关损耗签核**。电源树联合启停经常跨越空载、DCM 与掉电，采用下面单独说明的寄生电容策略。

可切换“常数 Coss/Cj 开关边沿”，使用用户常数电容及栅电容近似，耗时更长，仍不是完整晶体管模型。默认单线程避免小电路的线程调度开销。未启用故障关断时使用精简监督状态，不计算无关打嗝定时；启用打嗝／锁存后自动选用完整通用保护状态。

### 通用 MOS 与二极管连续过渡（模型 1.1–1.3）

`GenericBuckBoostPWM-1.1` 将功率开关原先的理想正迟滞跳变，改为与反激通用 MOS 一致的连续电导过渡。P-MOS 按 Vsg、N-MOS 按 Vgs 控制，中心仍为 `VG/2`，负 `Vh=-0.2×VG` 对应约 `0.3×VG～0.7×VG` 的过渡区。开通电阻、关闭电阻及用户器件参数不变；内部 PWM 锁存、采样、限流和保护门限也不变。

这里的过渡宽度是通用行为模型的换流近似，**不是所选 MOS 的真实门槛、跨导、米勒平台或栅电荷模型**。它避免零寄生快速模型中功率开关突然跳变给求解器造成不连续；不能依据其过渡时间或瞬时损耗签核实际 MOS。即使启用常数 Coss/Cj，仍须保留这一模型边界。导出 `manifest.json` 的 `mos_transition` 与 `approximation_notes` 明确记录这些信息，独立单元与电源树使用同一库。

模型 1.2 在此基础上，为 Buck/Boost 的功率二极管和体二极管显式设置 `EPS=1µV`，使用 LTspice 的二次函数使 I–V 转折处数值及斜率连续。**Vf、Ron、Roff 均不变**，并没有加入真实结电容或反向恢复。共用 `GPWR_DIODE` 的 EPS 默认仍为 0，其他拓扑未指定 EPS 时保持原行为；`manifest.json` 的 `diode_transition` 记录本次近似。电源树中外部源的输出电容及 ESR 是单独、明确的源配置，不由本库偷偷加入；完整示例采用的源端 10µF/0.1Ω 属于示例工程假设，不能当作所有实际电源的参数。

2026-11-11 模型 **1.1 历史回归**以当前随附三例的同一套硬件，在 Vinmin 做真实 LTspice 短回归：16ms 结束、12ms 阶跃、1 线程，保留原补偿、软启动、控制门限、求解容差和最大步长。三例均完成，日志 0 警告、0 错误，FAULT 全程为 0：

| 原型 | 输入 | 末 1ms 输出均值 | 保存 RAW 点数 |
|---|---:|---:|---:|
| TPS40200 参考 Buck 电压模式 | 18V | 12.00638V | 25,882 |
| LTC3864 参考 Buck 峰值电流模式 | 18V | 11.99997V | 23,925 |
| LM5022 参考 Boost 峰值电流模式 | 9V | 24.00008V | 24,907 |

这是模型修改后的启动与负载阶跃短验证，不替代 Vinmax、FRA、保护和真实器件开关损耗验证。沿用单元导出的 RAW 压缩设置，点数不作为精度或性能优劣的依据。运行脚本为 `tests/nonisolated_transition_live.py`；本轮完整输入、库哈希、实际日志与 RAW 留在 `artifacts/nonisolated-switch-v1.1-live/`，汇总为 `receipt.json`。无新仿真证据时不沿用这一表格冒称其他配置通过。

### 振荡器周期计时与有限回零（模型 1.3）

模型 **1.3** 将内部周期计时 `age` 原先的 1ps 回零改为有限时间回零。定义周期 `T=1/fs`、回零时长 `Tr=min(1ns,0.001T,(1−Dmax)T/2)`，计时源峰值与上升时长都取 `T−Tr`，下降时长取 `Tr`，周期仍为 T。因此有效 PWM 窗口内 **age 等于本周期已经过的时间，上升斜率严格为 1**；回零完全位于最大占空比之后的关断区。高频或较高 Dmax 时自动缩短 Tr，避免负脉宽。常用频率下的 1ns 与已有时钟边沿一致，不代表真实芯片的内部振荡器实测波形。

这里没有保留“峰值 T、上升 T−Tr”的临时诊断形式，因它会使 age 的上升斜率略大于 1。正式模型保持调制斜率、频率及比较器门限，不以改变 PWM 增益来规避收敛问题。导出的 `oscillator_age` 记录周期、回零时长、峰值、上升时长与斜率，单独电源及电源树使用同一库。

定位依据来自完整分阶段示例的已完成但带警告记录：暖重启的 2572 条容差放松警告全部集中在 29.36ms 周期回零附近约 0.195ns 内；弱源的 59 条警告也全部发生在周期边界附近。对应时刻两路 Buck 均 EN=0、SS=0、COMP=0，暖重启尚未真正使能；它们不能解释为实际芯片的软启动振荡，也不能将带警告结果当作数值验收通过。有限回零针对的是这个人工 1ps 时间尺度，保留已启用的器件寄生与原求解容差。

冻结相同源、负载、硬件与控制配置，只修改该计时源的两次独立对照结果：暖重启完整 **55ms / 1,688,771 点 / 0 警告 / 0 错误**；弱源完整 **25ms / 191,913 点 / 0 警告 / 0 错误**。暖重启末值为 11.986854V、4.987163V、3.294990V，阶段恢复为 2/3/3；弱源仍按预期无法建立输出，并非为消除警告而放宽限流。证据分别保存在 `artifacts/sequence-staged-review/r7-warm-exact-age-reset-r2/` 与 `r7-weak-exact-age-reset-r2/`，含逐行网表差异与原始日志。这些是模型修正对照，四场景正式验收单独记录，旧警告记录不作覆盖。

正式 **1.3** 共用库另以三个单元原型做 Vinmin、16ms、12ms 阶跃、单线程真实 LTspice 回归，三例均完成，0 警告、0 错误、FAULT 为 0。Buck 电压模式、Buck 峰值电流模式、Boost 峰值电流模式的末 1ms 输出均值依次为 **12.006391V、11.999983V、24.000033V**。此次增加保存内部 age，用实际 RAW 检查有效 PWM 窗口内 `age=time mod T`；三个实例最大绝对差依次为 **1.156ps、1.294ps、1.263ps**，均低于 4ps 检查阈值（包含 RAW 单精度存储误差），从而直接检查计时关系，而非只依据最终输出接近目标。脚本仍为 `tests/nonisolated_transition_live.py`，完整证据在 `artifacts/nonisolated-switch-v1.3-live/receipt.json` 及各原型目录；耗时包含当次启动和并发环境影响，不与历史耗时作性能比较。

### 联合启停：保留开关节点寄生电容

电源树联合启停入口默认保留 Buck/Boost 已配置的常数 Coss、Cj 与等效栅电容，在本次运行快照中使用 `niso_edge_model=1`；单个电源的快速模式设置不因此被静默改写。所用数值及模型切换必须在导出配置和报告中可追溯。已有器件参数优先，缺失参数应明确提示，不能为了运行成功任意填入电容。当前等效栅电容为 `Cg=Qg/Vgs`，Cj 若采用通用默认值仍标为假设，不当作所选二极管的实测数据。

原因不只是电压尖峰。非同步 Buck/Boost 进入 DCM 时，电感电流衰减至零，功率开关和整流二极管同时截止；若开关节点的 Coss/Cj 全为零，模型会从续流状态直接进入仅有很大关闭电阻的状态。退流可出现 `L/Roff` 量级的极短时间常数：例如 47µH 与 1GΩ 对应约 47fs。这是省略节点储能导致的数值刚性，不应误判为实际电路以该频率振荡，或一律归咎于补偿器过慢。保留器件寄生电容后，关断换流有明确储能路径；仍使用原求解容差和最大步长，不通过放宽精度掩盖失败。

2026-11-11 的完整分阶段电源树对照在零电容快速模式下出现对数值书写形式敏感的停滞：同一物理源电容的 `10u` 与 `1e-05` 导出曾分别完成和停在约 9.222ms，不能把选一个恰能完成的写法当作修复。另两次增大二极管转折至 10µV、100µV 的诊断均停在约 3.698ms，未采纳。该处节点监测显示开关已关闭、电感电流约 10⁻⁸A、COMP 远离上限，支持 DCM 零电流切换刚性的判断。**1µV 连续转折解决的是二极管 I–V 折点问题，不能声称它独自解决全部电源树收敛问题。**

随后从当前示例独立导出，唯一配置修改为两路 Buck 的 `niso_edge_model=1`。每路启用已有 Coss=179pF、Qg=53.1nC、Vgs=8V，即 Cg=6.6375nF；Cj=20pF 沿用已声明的通用假设。源端仍为明确配置的 10µF/0.1Ω，控制、保护、负载、容差和最大步长均未改。该次正常工况完整到达 **45ms，1,382,736 点，0 警告、0 错误，墙时 86.10s**。它证明本次完整正常日程完成，不替代其他故障与恢复场景验证。
