# COT 多相 Buck：工程配置与验证

## 1 对象与操作

本功能用于 1–16 相、共享单输出的同步 Buck。输入电压、输出功率和电容组按整机填写；L、DCR、MOS 和采样电阻按单相标称值填写。相数不是隔离输出路数。

桌面左侧「反馈与补偿」、本地 Python 网页「环路」页提供 **COT 控制、均流、保护与验收** 入口。五个页签统一管理控制、保护、供电/动态、报告验收及逐相参数。点击「应用到当前设计」后复算，保存工程会保留配置。桌面窗口为非模态。纯浏览器内核仍提示使用 Python 版本。

逐相表为 L、DCR、高低侧 Rds、导通定时和采样增益的倍率，以及单位为 A 的采样偏置。倍率只应用一次。改变相数时明确增删参数行，不截断已有数据。

## 2 控制与逐相工作点

旧工程保留「频率 PI」。增强「总电流反馈 COT」增加快速电流负反馈和有限带宽均流，参考 [TI TPS536C7 §7.6.2–7.6.3](https://www.ti.com/lit/ds/symlink/tps536c7.pdf) 的公开结构。软件增益为行为模型单位，并非芯片寄存器值；通用 16 相范围与参考芯片范围分别看待。

自适应导通时间由输入前馈产生，目标频率不是硬锁定频率。导通损耗、死区和均流修正使实际频率偏离目标。固定导通时间时，也需要复核输入和负载变化。

以第 j 相电流由开关节点流向输出为正，平均电流 Ij 用 A，电感 Lj 用 H，母线电压 Vb 和电容端电压 Vc 用 V。共用频率 fs 用 Hz；每相占空比 Dj 无量纲。

```text
Ton,0 = Vc / (Vb · ftarget)
Im,j = aj · Ij + bj
ΔDj = clip[ Kbal · (mean(Im) − Im,j) / Vb ]
Dj = fs · Ton,0 · kt,j + ΔDj
Σj Ij = Pout / Vout
Vb = Vin,after − Rsource · Σj (Dj Ij)
```

Ton,0 是基准导通时间（s）；aj 是采样倍率，bj 是偏置（A）；kt,j 是定时倍率；Kbal 是均流增益（V/A）；clip 按配置的绝对占空比限值截幅。Rsource 是输入路径串联电阻（Ω），Vin,after 是输入防反管后的源电压。Vout、Pout 在输出防反管后统计，反馈在防反管前电容端取样。

与每相一周期伏秒为零的条件联立，求 fs、Vb、各相电流和均流修正。死区按边沿电流方向选择体二极管；通用二极管为用户拐点电压加 5 mΩ 斜率电阻。输入两端保留同一组公共标称硬件与逐相倍率。各相 RMS、峰谷、损耗和合成纹波从同一组解得到。

## 3 环路与电容动态

增强平均模型保留 N 个电感电流状态、各电容状态、均流滤波和总电流滤波。公共电压误差用设定电压归一化，经 Kp+Ki/s 形成频率指令。Kp 单位 Hz，Ki 单位 Hz/s，s 为拉普拉斯变量（s⁻¹）。各颗 ESR 始终保留，ESL 按启用状态处理。

目标穿越频率上限为实际每相频率的 1/20，平均扫描上限为 1/10。工作点触及限流、最小关断时间或二极管仿真零电流区时，不给普通 CCM 小信号通过结论。源电阻直流压降进入工作点；输入 R/L/C 动态及详细死区换流用开关 FRA 核对。

动态电容分两层检查：电荷初筛假设响应延迟后立即按最大电流斜率调节；闭环时域按实际 PI、电流反馈和均流状态求响应和输出阻抗。初筛满足不代表实际闭环满足。

```text
Qu = ΔI · td + ΔI² / (2 Su)
Qd = ΔI · td + ΔI² / (2 Sd)
ΔV ≈ ΔI · ESRparallel + Q / Ctotal
```

ΔI 为负载变化量（A），td 为响应延迟（s），Su/Sd 为合成电感升降斜率（A/s），Qu/Qd 为亏缺/剩余电荷（C），Ctotal 为总输出容量（F）。即使理想交错抵消稳态纹波，动态容量仍须计算。最终用开关大信号核对保护和饱和。

## 4 启停、保护与容差

增强开关模型包含源上升时间、源 R/L、VCC 欠压、输入 UVLO 迟滞、软启动、逐相采样和限流延迟、逐周期/打嗝/锁存、输出过压、死区、预偏置及主动关机。轻载二极管仿真在电流过零时关闭低侧，反馈已达到参考时暂停追加脉冲；它与强制同步分别验证。

系统电源树复用单元功率级和控制器，外部母线、EN/VCC、负载唤醒电压和爬升由系统配置。整网报告读取各相电流、采样和限流探针。门极关闭与输出放电完成是两个判据。固定活动相数；自动减相状态机尚未接入。

逐相限流由采样增益和偏置换算实际触发电流，再计检测延迟中的电流增长；与电感 Isat 分别对比。Isat 的电感下降比例按厂商条件解释。蒙特卡洛可独立抽样各相倍率和有符号偏置，也可使用相关组；共同参数和相间分散不混为同一变量。

## 5 报告验收

稳态、启动、动态、关机、相间偏流及限流分别评价。输入峰流限值为 0 时只观察。共用「允许相间偏流」同时控制计算与报告；旧报告专用限值自动迁移，显式共用字段优先。

FRA 主幅/半幅采用相同频点，先验证测量线性，再判断 PM、GM、fc 及同频差。半幅一致不等于设计满足。频带内未测得相位交越时，GM 标为未覆盖。报告结论突出超限与未覆盖，逐相表保留实际数值。

内置工程采用真实器件及 80 A→40 A、1 µs、±60 mV 规格，见 [器件与验证依据](COT_REFERENCE_PARTS.md)。相关原厂资料还包括 [TI SLVA882B 多相 Buck](https://www.ti.com/lit/an/slva882b/slva882b.pdf) 和 [SNVA166A COT 设计](https://www.ti.com/lit/an/snva166a/snva166a.pdf)；其理想关系用于初筛，器件失配另行求解。
