# 控制器功能框图

在桌面版「LTspice 通用电源闭环 · 配置与导出」或本地网页「报告与检查」中，可将仿真参数与控制器信号路径对应起来。右侧按芯片功能框图的阅读习惯绘制引脚、比较器、锁存器、驱动及信号走向。虚线框标识控制器模型范围，外部反馈、功率级和试验设置分开放置。

## 查看参数与信号

左侧输入区保留各组参数。选中输入框时，右侧相关符号变蓝，图下方显示参数的当前值、单位、作用和适用条件。点击符号可查看对应说明。修改暂存值后，说明同步更新。点击「应用到计算器」写入当前设置。

桌面默认让框图占用较宽区域，可拖动中间分隔条。「适合窗口」显示图的全貌；用「＋」放大后，可通过滚动条查看局部。网页在空间较小时将输入和图上下排列。

## 以 L6565 准谐振反激为例

L6565 参考图按 ZCD、CS、COMP、VFF、VCC 和 GD 引脚组织。下表描述软件仿真模型中的动作，适用于外部隔离反馈和理想 VCC 供电配置。 [ST L6565 规格书，第 1 页功能框图](https://www.st.com/resource/en/datasheet/l6565.pdf)

| 信号 | 在仿真模型中的作用 |
| --- | --- |
| ZCD | 检测所选绕组退磁。信号通过边沿检测和关断消隐，随后可置位锁存器。无检测信号时，启动定时器提供另一路置位条件。 |
| CS | 采样经过滤波和增益，与 COMP 命令比较，达到阈值后复位锁存器。异常过流通过独立比较与锁存路径禁止驱动。 |
| COMP、VFF | 外部补偿产生 COMP 电流指令，固定 VFF 配置影响逐周期上限。 |
| VCC、GD | VCC 欠压判据决定启动许可并清除异常过流锁存。锁存输出经驱动送到 MOS 栅极。 |

固定频率反激、正激及 Buck/Boost 的 PWM 图按控制方式显示时钟、斜坡、采样和比较路径。正激另画 GATE 与 SYNC。多相 Buck COT 显示频率指令、相位分配及各相固定导通时间。

## 实现与核对

`controller_logic.py` 提供参数说明与各拓扑的框图数据，桌面 Canvas 和网页 SVG 使用同一数据。画布缩放、焦点切换及参数解释只更新界面。控制器参数、导出及仿真仍走原有入口。
