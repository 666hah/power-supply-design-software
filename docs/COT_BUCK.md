# 同步 Buck 恒定导通时间控制

2026-11-15 增强版已加入逐相失配、有限带宽均流、总电流反馈、保护、源阻抗和动态验收。入口、公式适用范围与新例程见 [COT 工程配置与验证](COT_ENGINEERING.md)。下面的同参数公式保留为均衡特例；新模型逐相求解，旧工程仍可选择原频率 PI。

选择 **Buck**。相数为 1 时可以使用原电压模式、峰值电流模式或 COT。选 2–16 相时，使用 **COT**。各相由高侧及低侧 MOS 与一颗独立电感组成，连接同一输入母线和同一输出，输入输出电容组由所有相共用。这里的相数与隔离电源的输出路数无关。

## 录入和查看

1. 输入端电压、输出端电压和输出功率使用整台电源的需求。电感量、DCR、高低侧 MOS 参数和采样电阻均按单相填写。电容组填写实际共用的电容。
2. 开关频率填写每相的目标值。导通时间为 0 时根据输入前馈计算，正值为固定导通时间。最小关断时间填写控制器或设计约束。采用固定导通时间时，应按整个输入范围检查实际开关频率。
3. 查看功率级中的各相电流、合成电感电流、输入脉冲电流和输出纹波。电感额定电流及磁件温升按单相检查。输入电容和输出电容按所见合成电流计算。
4. 内置「4 相同步 Buck · COT」为 10–14 V 输入、1.2 V / 80 A。新版每相 0.30 µH，目标每相频率 400 kHz，使用实际器件及逐相失配；器件与条件见 [选型依据](COT_REFERENCE_PARTS.md)。

## 稳态计算

以相电感电流从开关节点流向输出为正。以真实输出端口电压和总输出功率求总负载电流，按活动相数 `N` 均分得 `Iφ`（A）。计入输入防反压降后的母线电压记为 `Vbus`（V）。反馈取样及电容端电压记为 `Vcap`（V）。

```text
Vrise = Vbus − Vcap − Iφ (RH + RS + RL,DCR)
Vfall = Vcap + Iφ (RL + RL,DCR)
D = Vfall / (Vrise + Vfall)
Ton = Vcap / (Vbus ftarget)      （自适应输入前馈）
fs = D / Ton
Toff = 1/fs − Ton
ΔIφ = Vrise Ton / Lφ
```

`RH` 与 `RL` 分别为单相的高侧、低侧导通电阻（Ω），`RS` 为单相高侧采样电阻（Ω），`RL,DCR` 为电感直流电阻（Ω）。`Lφ` 为单相电感（H），`D` 为每相占空比，`Ton/Toff` 用秒，`ftarget` 和 `fs` 用 Hz。压降按相平均电流计算。磁件或器件变化时重新检查导通压降和最小关断时间，超出定时条件的角点会给出原因。

各相相位均匀错开 `T/N`，其中 `T=1/fs`。令 `a=ND−floor(ND)`，在同参数、规则交错、线性电流斜坡下，合成电感电流峰峰值为 `(Vrise+Vfall)T a(1−a)/(N Lφ)`。理想的 `ND` 为整数时，该纹波项可抵消。输出电容仍按实际 ESR、频域分流和动态负载需求选型。前馈自适应频率由于导通压降可略偏离目标每相频率。

## 公共电压外环

在一个输入与负载工况下，使用稳态导通时间 `Ton` 线性化。各相以相同的频率增量 `Δf` 调节，共用一个电容端取样。`Δf` 的单位为 Hz，`ΔD` 为每相占空比的小扰动。负反馈方向定义为取样电压升高时减小触发频率。

```text
ΔD = Ton·Δf
Rφ = D·(RH + RS) + (1−D)·RL + RL,DCR
VΔ = Vbus − Iφ·(RH + RS − RL)
Zk(s) = ESRk + s·ESLk + 1/(s·Ck)
Zo(s) = [1/Rload + Σk 1/Zk(s)]⁻¹
Gvf(s) = Ton·VΔ·Zo(s) / [s·Lφ/N + Rφ/N + Zo(s)]
T(s) = Gvf(s)·(Kp + Ki/s)/Vset
```

`Rφ` 是单相平均导通电阻（Ω），`VΔ` 是高低侧切换产生的电感电压斜率驱动量（V）。`Rload` 是输出端口等效负载电阻（Ω）。防反管采用固定压降，电容端与输出端的电压小扰动相同。`s` 是拉普拉斯变量（s⁻¹）。第 `k` 颗电容的 `ESRk`、`ESLk` 和 `Ck` 分别用 Ω、H 和 F。ESR 始终按各颗电容计入，打开输出电容 ESL 时使用每颗电容的 ESL。`Zo` 为负载与各电容支路构成的端口阻抗（Ω）。`Gvf` 是每相频率指令到电容端电压的传递函数（V/Hz），`T` 是无量纲开环增益。`Vset` 为防反管前电容端电压设定值（V）。`Kp` 和 `Ki` 对应以 `Vset` 归一化的误差，单位为 Hz 和 Hz/s。

在「环路」页查看 Bode 图、穿越频率、相位裕度和增益裕度。扫描上限取实际每相频率的 1/10，增益裕度在该频带内判读。自动整定的目标穿越频率不超过每相频率的 1/20。触发频率已到最小关断时间的工况无法做双向线性化。模型假设标称均流、固定活动相数和强制同步；各相电流差的动态、分相延时、轻载减相、跳脉冲及芯片专用触发或纹波注入需另行验证。

`Kp` 与 `Ki` 同时填 0 时采用默认选值。正 `Ki` 与零 `Kp` 对应纯积分。默认使用 `Kp=0.15·ftarget` 和 `Ki=2π·ftarget·min(800 Hz, ftarget/50, fLC/10)`，其中 `fLC=1/(2π√[(Lφ/N)·Σk Ck])`。手动录入或接受自动整定候选后，工程会保存一组固定增益。用这组增益重新计算输入两端，再检查所需负载角点。整定与计算均按频率 PI，无需换算为二型或三型阻容网络。

历史四相 0.47 µH、原频率 PI 算例的计算穿越频率约为 777 Hz 和 779 Hz，相位裕度约为 96°；这些数值仅用于旧归档追溯。当前内置例程采用总电流反馈及 20 kHz / 80° 整定目标，按同一硬件和 PI 复算两端。计算与有效 FRA 的最小相位裕度须严格大于 45°。

## 控制器参考和边界

- [TI D-CAP+ 架构](https://www.ti.com/document-viewer/lit/html/sszt895)和 [TPS536C7 数据手册 §7.6.4](https://www.ti.com/lit/ds/symlink/tps536c7.pdf)区分反馈触发、输入前馈、导通定时和均流调节。软件的计算模式使用定时与标称均流条件。
- [TI 多相 Buck 设计 SLVA882B](https://www.ti.com/lit/an/slva882b/slva882b.pdf)给出交错条件下输入电容 RMS 与输出纹波设计。板上布线及电感公差会改变实际抵消程度。
- [MPS MP29816-C](https://www.monolithicpower.com/en/mp29816-c.html)是单输出可达 16 相的原厂架构参考。`N=16` 表示计算器的配置范围。
- [Sridhar、Li，APEC 2024](https://hub.hku.hk/handle/10722/377405)讨论多相 COT 在 `D>1/N` 时的相位重叠和小信号调制。程序保留重叠波形和强制同步的负谷值，环路页说明 COT 的适用模型。验证均流、轻载减相、跳脉冲、输入滤波互动及相位裕度时，需要具体控制器和对应工况证据。

## LTspice 对比

从「导出报告」进入电路仿真与设计对比。COT 使用独立的 1–16 相同步开关网表。控制器以输出误差调节发脉冲的节奏，按相位顺序发送固定宽度的单稳态脉冲。自适应模式用输入前馈决定脉宽。工程 ZIP 提供 ASC 结构图和经过运行验证的 CIR 与 INCLUDE 网表。对比归档还保存波形、参数及日志。对比报告在通过稳态检查后列输出平均值、纹波、相电流、实际频率和脉宽。

旧开关电路保留原频率 PI 路径。增强电路使用逐相器件、采样与均流参数，包含保护、预偏置、轻载二极管仿真和输入源阻抗。系统电源树启停复用该单元，报告读取各相独立限流探针。自动减相状态机仍未接入。

需要对照环路时，开启实际开关模型 FRA，再运行电路仿真对比报告。FRA 在防反管前电容与反馈取样之间注入扰动。起止频率应覆盖计算穿越频率两侧，注入峰峰值按该节点设定电压的百分比填写。提高频点密度或压低起始频率会增加求解时间。比较只使用本工况的有效频带及通过检查的测量点。
