# 开关电源设计与环路分析使用手册

本手册介绍如何从系统架构进入电源单元，配置规格与器件，检查工作点并导出可追溯的报告。计算公式和模型推导见《计算方法与公式说明》。各操作使用保存后的工程参数，同一报告内的工况和器件应能够对应到同一份配置。

## 1 启动和保存工程

1. 打开桌面程序。便携版保留可执行文件同目录的 `_internal`。使用本地 Python 网页版时，在发布目录运行 `StartWeb.cmd` 后从浏览器打开本机服务。源码和发布方式见[项目结构](PROJECT_STRUCTURE.md)。
2. 在架构画布添加输入源、电源模块、LDO、OR 汇流或负载。从供电端口连接到受电端口。连线后，如需采用上游的电压范围，显式执行电压同步。
3. 双击电源单元进入详细设计。返回画布会回存单元修改。用系统保存功能写出整个工程 JSON，单元的“文件 → 保存配置”则导出单个单元。
4. “架构示例”提供分阶段电源树和双源二极管 OR 汇流参考例。单元“示例”提供三路有源钳位正激、三路 CCM 反激、L6565 准谐振反激、Buck 两种控制模式及 Boost。载入后核对输入范围、输出和器件条件。示例清单见[内置电源与控制器示例](BUILTIN_EXAMPLES.md)。

“功能架构”可在操作工程时保持打开。点击任意功能卡片，或在窗口的教程列表选择对应功能，可打开带界面截图的操作教程。教程说明字段的单位、用途及核对方法。[操作教程目录](../resources/help/operations/index.html)

画布预算按各单元的输出负担与预设效率估算。沿同一支路传递的功率按端口计入，检查源独供时尤其要看 OR 汇流后电压和每个上游端口的可供功率。详见[多源供电网络](AUX_POWER_NETWORK.md)。

## 2 配置单个电源

### 2.1 需求和输入工况

先选拓扑和控制方式，再填输入下限 Vinmin、上限 Vinmax、输出功率、电压、开关频率或频率上限及纹波目标。两端计算用同一套器件和磁件。界面切换端点用于查看相应结果。预设效率用于估计功率级负担，最终效率由损耗求得。详见[输入端点](INPUT_VOLTAGE_RANGE.md)。

“自动设计 → 按规格生成初版”支持 Buck、Boost 与反激中已接入的模式。填写要求、生成、查看端点检查，再决定是否采用。《自动计算参数依据》解释选值规则、厂商依据及项目余量。

### 2.2 器件和曲线

在「器件模型精度选择」按需选择固定参数或曲线模型。曲线在相应的 MOS、整流、续流或防反器件树导入和预览。MOS 转移曲线横轴为栅源电压、纵轴为漏极电流。栅电荷曲线横轴为电荷、纵轴为栅源电压。二极管曲线横轴为正向压降、纵轴为正向电流。导入时核对倍率及测试条件。曲线覆盖不足或外推时查看报告中的提示。[操作说明](DEVICE_CURVE_HUB.md)

在对应的输入或输出电容组填写数量、C、ESR、ESL 和热阻，或导入阻抗扫频数据。到「器件模型精度选择」按位号选择固定参数或阻抗曲线。切回固定参数后仍可重新启用已存曲线。[电容模型说明](CAPACITOR_IMPEDANCE.md)

打开「① 拓扑」旁的「② 器件 BOM 与规格」。按位号填写实际器件的额定值，点击「应用当前器件」，再核对 MOS 阻断平台与尖峰、整流二极管反压、电容电压与 RMS 纹波电流、电阻平均耗散。二极管模型未覆盖的寄生反压尖峰需要另行复核。详见[器件与降额](COMPONENT_BOM_DERATING.md)和[应力与温升](THERMAL_AND_STRESS.md)。

### 2.3 多路输出和反馈

隔离拓扑可配置最多六路输出。负载端口定义在输出防反管之后，SSR 主反馈取样在所选一路的防反管之前。其他绕组的参考电压由整数匝比及模型压降推得。需要交叉调整率时，先填每路最小、最大功率，再检查求解方式和绕组耦合输入。定频反激、准谐振反激和有源钳位正激采用各自的路径。失败或未覆盖的工况保留原因。详见[电压与反馈节点](OUTPUT_FEEDBACK_NODES.md)及[交叉调整率](CROSS_REGULATION.md)。

## 3 检查工作点和环路

| 项目 | 先看什么 |
| --- | --- |
| 功率级 | 输入端点、导通模式、占空比、器件电流方向与峰值 |
| 磁件 | 饱和裕量、绕组 RMS 电流及电流密度、线束排布、铜损和温升 |
| 电容 | 每颗电容的 C、ESR、ESL、分流与损耗，注意统计带宽 |
| 环路 | 环路模型、穿越频率、相位裕度和增益裕度。验收取有效 0 dB 穿越中的最小相位裕度，须严格大于 45°。整定目标可单独设置 |
| 器件 | 厂商额定值、实际应力、采用的降额限值与证据来源 |
| 效率 | 计算效率、总损耗和最大损耗项，再看损耗分解与效率负载曲线 |
| 钳位 | 钳位电压、电阻损耗和关键器件应力，再看电压或复位电流波形 |

效率与钳位的双图在宽窗口并排显示。结果栏较窄时上下排列，可滚动查看后半页。

在磁件页的「变压器可绕制评估」设置净窗口、绝缘、交错层序和逐匝位置。程序按各绕组路径自动计算平均匝长、线长与 DCR。非标准磁芯填写有效截面积、有效体积和窗口面积，有骨架实测路径时在三维建模设置录入。变压器温升按整体至环境热阻估算，独立电感使用对应对流模型。详见[绕制窗口](WINDING_WINDOW.md)、[绕组电参数](TRANSFORMER_ELECTRICAL.md)和[自定义磁芯](CUSTOM_CORES.md)。

点击磁件页“3D 结构预览”，可在独立窗口旋转查看半透明磁芯和深色线圈。支持逐层显示、分解装配和视图导出；二维窗口的逐匝修改会同步更新，旋转视角不触发重新计算。模型库显示所用厂家参考型号和尺寸来源。操作及几何定义见[变压器三维预览](TRANSFORMER_3D_PREVIEW.md)。

在环路页核对控制模式及补偿目标。整定后先查看两端点的环路结果，再按实际补偿网络计算元件。没有有效穿越或未覆盖的模型会单独标注。小信号环路、PSR 轻载估算、实际 FRA 与样机测试的结论须对应各自的工作区间。

同步 COT Buck 使用电压外环 PI。在左侧电路需求录入比例增益 Kp（Hz）和积分增益 Ki（Hz/s），两个值均填 0 时使用默认增益。四相示例可以直接在「环路」页尝试 1 kHz、92° 并查看写回后的两端点 Bode。配置 LTspice 对比时可启用开关 FRA，报告会标明经两档注入幅值复核的频点。[COT 环路与操作](COT_BUCK.md)

## 4 仿真和工程复核

在单元设计页顶部点击「仿真配置中心」。在「电路仿真」导出 LTspice 工程或运行对比。「联合仿真」从当前配置组织变压器场解、回填裕量、设计复算和电路仿真。首次使用时选择本机工具与模型。查看结果后如需写回设计，执行“采用结果到当前单元”，再保存系统工程。[联合仿真操作](JOINT_SIMULATION.md) · [便携配置](PORTABLE_SIMULATION.md)

整网启动、掉电与主备切换在画布的“联合启停仿真”配置。核对外部源保护、各单元输入门限、软启动、负载分段以及实际门极与输入电流。先确认使用的行为模型，再解释仿真结果。[联合启停说明](SYSTEM_STARTUP_SHUTDOWN.md)

在单元设计页打开「⑪ 硬件容差边界与分布评估」。核对负载及器件上下限，点击「计算极限容差」，查看理论边界和已算候选的最不利值。发现超限后，可设置分布并点击「运行蒙特卡洛」。[容差评估说明](TOLERANCE_ANALYSIS.md)

直接打开「⑫ 工程验证与验收」，核对器件规格和电源外特性。限值来自器件 BOM、磁件参数、需求和环路。导入匹配当前硬件的仿真或补录实测后，可按指标与端点查看来源、限值及裕量。[验收说明](ENGINEERING_ACCEPTANCE.md)

## 5 导出与阅读报告

单元的“导出报告”提供 Word、Excel 和 Markdown 设计报告。不同输入端点并列比较，共用硬件和拓扑集中说明。固定输入显示一套结果。先查看结论及待复核项，再按对应工况阅读波形、应力、损耗与环路。系统级交付使用画布的“生成系统报告包”，打开包内状态清单核对已完成和失败的单元。
