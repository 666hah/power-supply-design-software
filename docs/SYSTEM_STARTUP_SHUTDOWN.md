# 画布级联合启机、关机与主备 OR 切换

更新日期：2026-11-11。本文对应向后兼容的 `power.system-sequence/1` 配置合同，以及 `system_sequence_config.py`、`system_sequence_behavior.py`、`system_sequence_units.py`、`system_sequence_export.py`、`system_sequence_analysis.py`。旧工程未声明的新字段沿用“源门限仅比较、单次电压斜坡、单阶段负载”；不会自动开启实际限流或改变负载。具体运行证据在本文末尾单独登记；配置能够保存、电路能够导出或分析返回 `completed`，均不表示整机已经验证通过。

## 1. 模型做什么

联合启停把当前供电画布中的多个电源、外部输入、连接、二极管 OR 和实际负载装入**同一次开关级瞬态电路**。开关电源复用已有导出的功率级、变压器/电感、输入输出电容、采样电阻、反馈、通用行为控制器及其已实现的保护。各输出电压由该电路求解；不是用预设输出电压斜坡代替整个电源。

外部输入的上升/下降波形、画布层 EN、输入 UVLO、等待端口条件、终端负载和支路阻抗属于联合实验夹具。它们与单元内部控制器共同作用：下游开始耗功会增加上游电流；电容充电、源阻抗和功率级限流会改变电压建立过程；输入掉电、EN 关闭后，电压按实际保留的通路及电容继续变化。

这与 [可配置辅源供电网络](AUX_POWER_NETWORK.md) 中的稳态架构预算分开。原预算用额定输出功率/预设效率检查容量和供电范围；联合瞬态中移除单元原有的额定测试负载，实际电流通过同一张电路传递，不能把稳态预算值再作为额外耗功叠加。

当前支持范围：

| 单元 | 联合实验中的模型 |
| --- | --- |
| Buck、Boost、定频反激、QR 反激、有源钳位正激 | 已有开关功率级与通用行为控制器子电路；只接受当前导出器支持的 SSR 路径 |
| LDO | 压差、有限输出电阻、静态耗流及可选显式限流的行为近似，见第 6 节 |
| 二极管 OR | 每支路二极管、串联 R 和可选 L；由瞬时电压决定供流 |
| 外部输入源 | 可编辑电压时序、有限源阻抗、可选恒流/折返/打嗝保护及回流能力声明 |
| 自定义负载及额外端口负载 | R/I/P 分阶段总需求、多轨就绪条件、掉压复位、延时、建立时间、静态耗流、额外电容和泄放 |

未支持的开关拓扑或 PSR 路径应拒绝导出，不能悄悄换成理想电源。这里的“实际开关级”指网表保留开关动作与功率级储能元件；控制器仍是项目通用行为模型，不是原厂硅片模型或实物测量。

## 2. 从画布配置并运行

桌面画布工具栏的“联合启停仿真”打开集中配置窗口。输入源、电源启停、负载和支路分别按画布稳定 ID 编辑；内部使用 SI 单位，界面以 ms、µs、mΩ、µH、µF 等显示。

1. 先核对画布的供电端口、直连/二极管方式、输出路数和各单元的电气及控制器配置。下级输入和终端负载接在上级输出防反后的端口，SSR 反馈保留单元内部防反前电容节点。
2. 设置本次整网使用 `Vinmin` 或 `Vinmax`，以及足以包含启动、切换、关断和所需残压观察时间的 `stop_s`。一次任务只运行一个整网端点；不能据单端结果声称另一端已经覆盖。
3. 逐源选择“仅比较”或明确的保护模式，设置阻抗和上升/下降时刻；需要多次掉电恢复时打开“电压时序”表。逐单元设置 EN、输入 UVLO、可选软启动覆盖和等待端口；逐负载设置本地耗功阈值、多轨就绪条件及分阶段总需求。
4. 列表弹窗可增删、修改时序/阶段/就绪条件，无需填写 JSON；时间项保存时按时刻排序。先“保存列表”回到本次配置草稿，再点主窗口“应用并保存”，最后保存/导出系统工程，`sequence_config` 才随工程文件交付。取消列表不修改原表。应用配置不会自动运行仿真。
5. 开始运行时冻结一份工程快照。后续画布修改不改变本次输入；修改后的工程需另跑。LTspice 路径和本机结果目录属于本机运行设置，不应成为电气工程的绝对路径依赖。
6. 查看日志、完整 RAW 分析、事件和模型边界。取消或超时要保留本次日志和已生成证据，不能引用旧任务结果作为本轮完成。

`sequence_config` 顶层分组为 `schema`、`settings`、`sources`、`units`、`loads`、`rail_loads`、`connections`。记录按稳定节点/连线 ID 保存；端口使用 `PSU-01/OUT1` 这样的 ID。被删除节点的配置可作为不参与导出的草稿保留；等待端口已经不存在时，导出必须明确报错。

## 3. 参数合同与含义

### 3.1 运行、输入源和连接

| 分组/字段 | 含义与边界 |
| --- | --- |
| `settings.stop_s` | 从 t=0 运行至指定时刻；默认 40 ms 只是实验初值，不保证已覆盖慢启动或掉电尾部 |
| `timeout_s`、`threads` | 本次运行超时与 LTspice 线程数；线程数不改变模型定义 |
| `vin_case` | `min` 或 `max`，各外部源分别取画布中对应端点，所有单元保持同一套硬件 |
| `max_step_s` | 0 为自动；按各开关单元频率取 `min(1/(80f))`。只含 LDO 时自动上限为 2 µs；手填值不得比自动要求更大 |
| `include_switching_capacitance` | 默认 true（旧工程缺省亦同），仅在本次联合电路中保留 Buck/Boost 已填 Coss、Qg/Vgs 等效栅电容及 Cj；false 时沿用单元自己的边沿设置。不会改写单元原参数，物理意义和边界见第 10 节 |
| 源 `on_s`、`rise_s` | 从 0V 开始上升的时刻与上升时间 |
| 源 `off_s`、`fall_s` | 从端点电压开始下降的时刻与下降时间；不是“完全断开”的理想开关 |
| 源 `voltage_profile` | 可选 `{time_s,level}` 列表。`level` 是所选输入端点的电压倍率，1 表示该端点电压；非空时覆盖原四项单次斜坡时刻，见下文 |
| 源 `resistance_ohm`、`inductance_H` | 有限源阻抗；默认 50 mΩ、0H 仅为项目工程假设。仅比较模式支持串联 R/L；主动保护当前要求源 L=0，以免在没有续流/钳位定义时切断电感电流 |
| 源 `output_capacitance_F`、`output_esr_ohm` | 限流/阻断之后的外部源端口电容及ESR，与转换器自身Cin独立。旧工程默认0F（未建模），ESR默认0.1Ω，允许显式0Ω；应按真实供电器数据配置 |
| 源 `protection_mode` | `monitor`（默认，仅比较）、`cc`（恒流）、`foldback`（折返）、`hiccup`（限流后打嗝重试）；后三项实际改变外部源的电流与端口电压 |
| 源 `current_limit_A` | `monitor` 下仅比较 RAW 供流峰值，留空为未知；其他模式必须填写正值，是行为源的电流上限，不是下级变换器的开关峰值限流点 |
| 源 `foldback_short_A` | 仅折返模式使用：输出接近 0V 时的电流上限，必须为正且不大于 `current_limit_A` |
| 源 `trip_delay_s`、`retry_s` | 仅打嗝模式使用：连续限流达到前者后断开供流，休眠后者再尝试。默认 1 ms/10 ms 为工程初值，必须按实际源资料修订 |
| 源 `sink_current` | 默认 false，不允许向外部源回灌；true 时允许吸能，须有实际源能力依据。仅比较模式去掉理想阻断；主动模式对负电流也施加对称上限，打嗝时两个方向均断开 |
| 连接 `resistance_ohm`、`inductance_H` | 每条启用连接的串联 R/L；默认 10 mΩ、0H 仅为工程假设 |

上升、下降时间必须大于 0；源和连接 R 必须为正。0H 表示本次没有声明该处电感，不等于实物没有寄生。不得把默认阻抗当作实测值，或通过任意增大阻抗掩盖启动浪涌。

没有自定义电压表时，仍执行一次上升和一次下降，最终保持 0V。电压表须至少 2 点、最多 256 点，从 0 秒开始且时刻严格递增；相邻点线性插值，最后一点后保持其电压。电压倍率允许 0 至 10，倍率大于 1 是有意施加过压，不是自动容差。用“高电平—下降—低电平—恢复”的多点表可在同一次瞬态中观察热重启，电容残压自然延续；尚不提供任意端口预充初值。

主动源模型以命令电压 `Vc(t)` 和端口电压 `Vo(t)` 形成有限源阻抗需求 `Idemand=(Vc−Vo)/R`。恒流模式将正向电流限制在 0 至 `Ilimit`；允许吸流时下限为 `−Ilimit`。恒压/恒流转折处采用单调平滑夹限，避免理想硬转折使联合开关电路求解停滞；与理想夹限的电流差上界为当前限值的 0.1%，不会扩大限流上限。这是声明的源模型近似，不是放宽仿真容差。折返模式的瞬时限值为 `Ishort+(Ilimit−Ishort)×limit(Vo/max(Vc,1mV),0,1)`。这是电压相关的线性折返近似，源控制环带宽、实际 VI 特性及动态响应需由资料或测量确认。

声明源端电容后，内部源电流与端口电流分别统计：`current_probe`仍是限流器供流（包含向源端C充电），`output_capacitor_current_probe`正向为充电，`port_current_derivation=source-minus-capacitor`明确按源供流减C充电电流得到C之后的端口供流，不在回路串入额外元件。源停止供流时C仍能放电；端口短时供流可能大于内部限值，不能据此把限流器判断为失效。相反，源端残压也不表示内部电源仍在工作。零电容理想源没有这部分储能，未把数值失败自动改成不同电容值继续运行。

连接二极管采用固定Vf、Ron=1mΩ、Roff=1TΩ的分段线性模型，`sequence-diode-1.2`转折区为10µV二次连续过渡，保留设定Vf与膝区外的正反向斜率。该有限膝区属于明确的模型近似。Buck/Boost通用MOS与内部二极管也使用显式连续过渡（见对应模型说明，内部二极管仍为1µV），避免硬切换导致时间步缩小；这不等于器件真实动态参数或开关损耗模型。失败试验与修改前网表单独保存，未放宽求解容差。

完整负载后掉电的60ms例程中，旧连接模型1µV转折在重新上电且两Buck尚未使能时出现63条求解警告。冻结源、负载、时序和全部硬件，仅两只OR二极管改为10µV后，对照完整完成、零警告；相对带警告结果，100µs积分平均电压最大差0.252mV，阶段时刻最大差53.4ns。该比较只用于定位，不把旧带警告结果当作精度基准；正式验收另以相同模型重跑所有场景。证据位于`artifacts/sequence-staged-review/r9-warm-or-epsilon-10u/`与`r9-or-10u-comparison.json`。

打嗝模式先按恒流供电；**连续**处于限流状态达到 `trip_delay_s` 后休眠 `retry_s`，随后重试。中途退出限流会清零触发计时，命令电压不高于 1 mV 时复位故障锁存。该 1 mV 门限和逻辑传播时间是数值实现约定，不是实际源 UVLO。当前没有“源锁死、人工复位”模式。行为源的限流上限不代表真实源不存在短时过冲，不能据模型电流被夹住就宣称实物不会超流。

默认不吸流使用声明的行为近似：仅比较模式为零 Vf、1 µΩ 导通电阻的理想阻断，主动保护模式为电流下限 0；并不表示实物自动存在相同隔离器件。应依据实际电源和防反结构配置，尤其不能让一个本不具备吸能能力的源在掉电时替电容强制放电。

### 3.2 单元 EN、输入 UVLO、等待端口与 VCC

| 字段 | 含义与边界 |
| --- | --- |
| `enable_s`、`disable_s` | EN 最早允许启动与强制关闭时刻；`disable_s` 必须晚于 `enable_s` |
| `vin_on_V`、`vin_off_V` | 检测单元输入防反后母线的外加迟滞条件。须同时填写或同时留空，且启动阈值大于停止阈值 |
| `soft_start_s` | 开关单元可选覆盖已有 SPICE 软启动时间；留空是**不覆盖单元已有设置**，仍解析控制器的 `TSS`。LDO 填写后按该时间线性提升参考电压，留空不添加这一参考斜坡 |
| `wait_for_port` | 等待指定端口电压，空字符串表示不等待；不会根据供电连接自动推断 |
| `pg_threshold_V`、`pg_delay_s` | 前者为旧单一等待端口门限；后者为全部外部就绪条件连续成立后允许 EN 的延时。任何外部就绪条件退出都会重置该计时 |
| `pg_hysteresis_V` | 默认 0；正值时 PG 就绪条件在 `pg_threshold_V` 开启，在 `pg_threshold_V−pg_hysteresis_V` 关闭，迟滞须小于正启动阈值 |
| `ready_conditions` | 可选最多 32 项 `{port,on_V,off_V}`；每项有独立迟滞，所有项按 AND 合成，并与旧 `wait_for_port` 共同参与连续就绪计时 |
| `vcc_mode` | `ideal` 为独立恒定理想 VCC；`enable_follow` 为理想 VCC 跟随 EN |

实际 EN 是“画布单元启用、当前时间位于允许区间、已配置输入 UVLO 允许、等待端口条件满足”共同成立的结果。时间条件不是最终开关脉冲时间；单元内部 VCC UVLO、使能延时、软启动、反馈和保护仍可阻止开关或改变输出。

输入 UVLO 留空时，外加条件始终允许，不进行真实输入欠压动作验证。单元原控制器参数里的 UVLO 属于 **VCC 供电门限**，不能拿来替代高压母线或后级输入的 UVLO。当前外加 UVLO 使用项目设置的施密特行为夹具；10 ns 的传播/边沿时间是数值夹具参数，不是某芯片去抖规格。

“等待端口 PG”及多轨就绪目前是对端口电压的工程条件：根据配置的开启/关闭门限形成就绪状态，连续就绪达到延时后放行，退出就绪时重置计时。旧 `pg_hysteresis_V=0` 时没有迟滞；新列表每项必须 `on_V>off_V≥0`，且端口不得重复。列表为空保留旧配置行为。这里没有模拟真实开漏 PG 的上拉供电、逻辑电平和内部消隐电路，不得把它直接写成已经验证的芯片 PG 引脚行为。给后级增加依赖前要检查互相等待的死锁，例如两轨都必须等对方建立才允许 EN。

PG 等待、负载延时和 LDO 已配置的参考软启动，均使用 1 µA 给 1 µF 电容充电保存计时状态，即 1V/s；未就绪时经 SW 复位，复位时间常数为 10 ns。这些电容是逻辑计时代理，不属于母线储能。采用电路状态替代 `idt` 的条件复位表达式，是为避免把求解器未接受的 Newton 试探电压误记为历史复位；电容/电流和复位时间常数均是项目数值实现假设，不是芯片真实定时元件或消隐参数。

两种 VCC 模式都没有启动电阻、VCC 电容、辅助绕组供电接管及控制器偏置功耗。QR 异常 CS 故障锁存沿用内部模型：只关闭 EN 不清除锁存，VCC 降至其复位条件以下才复位。`enable_follow` 会改变这一复位条件，因此必须在证据中明示，不能用它代替真实辅助供电验证。

画布单元停用主要约束 EN，不删除单元电气元件。关 EN 不能保证端口被物理隔离：Boost 的输入电感/整流通路仍在；无 EN 的 LDO 也不会凭画布时刻虚构一个物理关断开关。

### 3.3 负载：何电压开始耗功

画布负载的允许电压 `min/max` 继续用于架构范围检查，与联合实验的耗功阈值 `on_V/off_V` 分开。允许电压下限不是自动启机点，额定功率也不是从 0V 起恒功率吸取。

| 字段 | 含义 |
| --- | --- |
| `enabled` | 是否装入这一组额外负载夹具；配置中关闭时该夹具的耗流、额外电容和泄放也不装入。与画布负载节点的启用状态不同，见下文 |
| `mode`、`power_W`、`nominal_voltage_V` | R/I/P 及额定功率和参考电压；参考电压为 0 时从端口标称值解析 |
| `on_V`、`off_V` | 耗功启动/停止阈值，须同时填写且上限大于下限；R 可留空，I/P 启用时必须填写正阈值 |
| `delay_s`、`ramp_s` | 每次达到启动条件后的等待时间、随后运行负载从 0 建立至目标的时间；条件撤销会复位计时 |
| `ready_conditions` | 本地耗功阈值以外的端口就绪列表；每项独立迟滞，全部条件与本地条件 AND。适用于控制板多电源轨均有效才释放复位 |
| `stages` | 可选最多 32 项 `{name,after_s,mode,power_W,ramp_s}`。非空时替代单阶段 `mode/power_W/ramp_s` 的运行需求，继续使用本地阈值、全部就绪条件和 `delay_s`；每阶段是总需求，见 3.4 节 |
| `off_current_A` | 关闭/等待时的待机电流；建立过程中按未运行比例逐渐退出，完整运行后不再叠加。低压时按下文线性缩放 |
| `input_capacitance_F`、`input_esr_ohm` | 只添加用户明确声明的额外负载输入电容及正 ESR |
| `bleeder_ohm` | 显式额外泄放电阻；留空不添加 |

令运行负载建立比例为 a(t)，参考电压为 Vn、额定功率为 Pn，则正电压下完整运行电流 Iactive 为：

- R：`Iactive = V × Pn / Vn²`，等效电阻为 `Vn²/Pn`。
- I：`Iactive = Pn/Vn`。
- P：`Iactive = Pn/max(V, Voff)`，并由正的迟滞启停阈值控制。

负载耗流为 `I = a(t) × Iactive + (1−a(t)) × Istandby(V)`；待机电流不在完整运行电流上再叠加。`Istandby(V) = off_current_A × limit(V/Vc, 0, 1)`，Vc 优先取正的 `off_V`；未配置时取 `min(1V, Vn)`，没有正参考电压时回退为 1V。在 0 至 Vc 之间线性缩放是项目的低压有限耗流假设，不是厂家 UVLO 或实测待机 I–V 曲线。

恒流 I 和恒功率 P 模式启用时都必须显式给出正的 `on_V`、`off_V`；不能在 0V 吸取额定电流，或用极小分母吸取额定功率。P 模式分母下界只是阈值切换附近的数值保护，不是负载在整个低压区的实测 I–V 曲线。数字板卡、风扇、电机等若没有相应实测行为，不能仅凭其额定功率认定恒功率模型适用。

额外电容和泄放不经过运行功耗的阈值/延时/建立比例控制；待机耗流则按上述未运行比例和低压规则计算。因此，负载尚未进入运行状态时仍可能出现充电与待机耗功；“首次有功耗”和“运行负载开启”应分开看。若只在画布上停用负载节点，而该负载配置 `enabled` 仍为 true，则只是阻止运行部分建立，仍保留该夹具的额外电容、泄放与待机耗流；将配置 `enabled` 设为 false 才移除整个额外夹具。

已声明任何下游连接的单元输出，默认不再叠加额定端口负载；即使该连接或下游当前停用，也不自动补回额定负载。没有下游连接的输出默认放置额定**恒阻**测试负载，可在 `rail_loads` 中停用或修改。手动再启用端口负载时，它就是额外真实耗功，不是仅供显示的容量标签。

每单元已有 Cin/Cout 保留。模块 EN 关闭时 Cin 仍可能从上游充电；关机后 Cout 按负载、泄放及半导体通路变化。不要把同一颗实际电容又在负载夹具中添加一次。

### 3.4 分阶段耗功与多轨掉压复位

一个控制板可以用多个负载节点代表不同供电引脚，例如 3.3V MCU、5V 采样通信、12V 驱动。它们仍分别接在真实供电端口；通过就绪条件表达“3.3V 和 5V 均有效才开始初始化”。只表达使能依赖，不在不同轨之间凭空创建供电或 I/O 回灌通路。

设全部就绪持续时间为 `age`，阶段相对时钟为 `τ=age−delay_s`。第一阶段必须 `after_s=0`；之后时刻严格递增，上一阶段的 `after_s+ramp_s` 不得晚于下一阶段开始。时刻是相对本次复位释放的时间，**不是仿真绝对时间**。当 `τ<0` 或任一条件失效，阶段编号为 0，运行需求关闭；重新满足条件后重新等待 `delay_s` 并从阶段 1 开始。

每个阶段的 `power_W` 表示该阶段的**总运行需求**。例如先 0.4W，后 1W，再 2W，最终为 2W；不能加成 3.4W。R/I/P 仍按 3.3 节的 `Iactive(V)` 解释，所以 I/R 的 `power_W` 是在 `nominal_voltage_V` 下折算的配置值，不保证所有瞬时电压下功率恒定。首阶段从 0 运行需求过渡，后续阶段在前后两个 `Iactive(V)` 之间线性过渡；允许需求下降或更换模式。待机电流仅在首阶段尚未建立的比例内保留，完整运行后不另叠加。

阶段切换与掉压只重置逻辑状态及计时，**不清空实际输入/输出电容**；额外电容、ESR 和泄放一直留在电路中。若短暂掉电未让监控电压降到 `off_V`，负载可能继续原阶段，这正是电容维持的结果，不能强行认定发生了热重启。若要模拟真实芯片对电源跌落、RESET 或固件状态的反应，应按其阈值和实测启动耗流修改阶段；当前没有自动复现 MCU 固件、电机机械状态或任意测得 I–V 曲线的功能。

## 4. 主辅源与二极管 OR

画布原有直连/二极管方式和 Vf 原样进入联合电路。每条启用支路有独立电流测量点及配置的串联 R/L；二极管是固定 Vf 加有限导通电阻的简化模型，不包含真实反向恢复、结电容、温度与 I–V 曲线。

可以通过主源、备用源不同的 `on_s/off_s/rise_s/fall_s` 或 `voltage_profile` 观察主源消失、恢复后的供流转移。例如备用源先保持供电，再让较高电压主源建立并随后下降；转换时刻由瞬时压差、二极管和负载共同决定。若源启用恒流/折返/打嗝，其保护也会改变供流。这里“主/备”是实验角色，普通二极管 OR 没有可编程优先级。

同压时不预设平均分流；支路阻抗和电源瞬时输出能力参与求解。若两路参数人为完全相同而出现近似均分，这只属于该对称模型，不证明实物有均流能力。正支路 R 避免了理想同压电源电流分配不定，但 R 值仍须有工程依据。

当前不模拟主动 MUX 的先断后通空窗、优先级、反向比较器延时或 FET 驱动。也不能把一个随意填写的 MUX 切换时间加到普通二极管上，或据此宣称任意主备系统无缝切换。切换前后须检查：母线最低电压、负载是否退出运行、备用源电流峰值、补充电容的充电浪涌，以及下级 EN/UVLO 是否反复动作。

## 5. 完整 RAW 分析与保护结论

`system_sequence_analysis.analyze(raw_path, manifest)` 读取这一实验的真实瞬态 RAW，不在分析中启动仿真器。统计使用全部有效采样；界面波形独立插值为最多 2400 点，显示点不用于峰值、能量或事件计数。事件列表最多展示 10000 条，超过上限应显示遗漏数量，计数仍来自完整 RAW。

| 对象 | 当前观察内容 |
| --- | --- |
| 输入源 | 供流/反向电流峰值及时间、端口电压、功率峰值与能量、配置门限比较；主动保护另记录限流有效及故障/休眠状态的进入退出 |
| 单元 | EN 与外加 UVLO 状态转换次数/时刻、输入电流及输入母线范围 |
| 输出 | 首次到标称 90% 的时刻、相对首次 EN 的延迟、预充标记、峰值/末值、末次 EN 关闭后的观察时间、残压及首次降到 10% 时刻 |
| 负载 | 建立比例越过观察阈值的事件、首次观察到耗功的时刻、峰值电流/功率和总能量；分阶段负载另记录就绪、实际阶段进入、复位/重启及运行电流探针 |
| 控制与保护 | 原始/滤波 CS 峰值、采样电阻及等效采样电流、周期限流正向证据、FAULT 转换；缺少探针则保持未知 |

这些统计阈值属于项目观察规则：输出 90%/10% 不等于器件 PG 或系统合格阈值；负载开启统计使用建立比例 0.001，首次功耗检测阈值为 `max(1 nW, Pn×10⁻⁶)`。传感器电流还可能包括待机、额外电容和泄放，不能把首次功耗直接当作处理器开始运行。

周期限流和 FAULT 必须分开。周期限流观察只在门极有效、经过模型声明的消隐/最小导通时间后，比较滤波 CS 与可用动态限流信号；QR 路径在缺动态信号时可比较明确的常数 CS 上限。观察到越限可以给出正向证据和**可观察次数下界**；没有采到越限、FAULT 一直为 0、或仅有静态 CS 裕量，都不能推出“未发生逐周期限流”。缺门极、滤波 CS、限流定义或消隐信息时，结论保持未知。LM5022 的限流还受斜坡参与影响，未把斜坡加入比较时仍只给正向证据下界。

原始 `Vcs/Rsense` 是采样支路等效峰值，不是任意拓扑的输出平均限流点。不能用电源额定输出电流、额定功率或 FAULT 的逻辑低，替代真正的 CS 比较器与保护定义。当前分析的 `protection_passed` 保持未知，不自动生成硬件保护合格结论。

外部源“限流有效/故障休眠”探针与单元内部 CS/FAULT 分开。“限流有效”表示未限幅的需求已达到当前电流上限；平滑转折使该时刻实际电流约为上限的 99.90%，不要求采样电流恰好碰到理想上限才开始计时。这是行为源内部状态，不是已读取某实物芯片的状态脚。源离开休眠只是开始重试，不表示后级已建立或负载完成所有阶段；应同时检查端口电压和阶段表。阶段编号 0 表示复位或等待，不表示端口电容已经无电。报告的阶段计划与实际进入时刻用于核对该逻辑，不能用计划的 `after_s` 代替实际进入时刻。

只有 RAW 覆盖要求的完整 0 至 `stop_s` 区间，且必要探针有效，分析才返回 `completed`。这个状态只表示本次 RAW 与统计完成；不检查所有启动都成功，也不代表重复启停、过压、保护或实物通过。时间区间不足或必要探针缺失为 `failed`；已有统计仅供诊断。首次到 90% 后又塌陷同样可能存在，应结合完整波形和事件判断，不能仅看首次到达时间。

## 6. 当前工程边界

- **公共返回 0：**画布只有正供电连接，所有单元明确共用 SPICE 0，保留单元内部已有次级参考。没有从布局推断独立隔离返回域、地线阻抗、地弹、安规或真实闭合回路寄生；多路隔离输出在此实验中共地，不构成实物接地方案验证。
- **外部源保护：**默认 `monitor` 仍只比较门限；显式选择 `cc/foldback/hiccup` 才改变电路。后三者为有限 R 与平滑夹限/逻辑定时的行为模型，没有真实源控制环、动态过冲、温度或器件容差，也没有锁死模式。源串 L 的主动保护尚未定义续流回路，因此拒绝导出；连接支路的已声明电感仍单独处理。
- **偏置供电：**VCC 采用前述理想假设，启动电阻、电容维持时间和辅助绕组接管未覆盖；不能用成功的主功率输出倒推控制器 VCC 一定能自举成功。
- **LDO：**输出目标约为 `max(0,min(Vref(t),Vin−dropout_max))`，通过配置的有限等效输出电阻产生正向电流；只有填写 `ldo_output_current_limit_A` 才施加该显式限流。额定电流不会自动当保护门限。填写 `soft_start_s` 时，Vref 按该时间从 0 线性提升至 Vout；有 EN 时由 EN 启动/复位计时，无 EN 时由输入超过下述 Vq 的条件启动计时，不能据此虚构物理 EN 或真实 UVLO。默认等效输出电阻 0.1Ω 是工程假设。输入静态耗流为 `Iq_max × limit(Vin/Vq, 0, 1)`：Vq 优先取已配置的 `input_rating_min`，未知时取非零 `dropout_max`，再回退至 0.1V，并统一至少取 0.1V；达到 Vq 后才使用完整 Iq。这一低压线性缩放是项目有限耗流假设，不是厂家 UVLO、关断电流规格或实测 Iq 曲线；当前 Iq 随输入电压变化，不因外加 EN 关闭而自动归零。线性参考软启动与恒定限流均为行为近似，没有厂家内部环路、折返、热保护、反灌或反向导电模型；无 EN 引脚时不能虚构 EN 切断，预偏置与掉电反灌需另验证。
- **电压模式 Buck：**TPS40200 路径斜坡按冻结名义 VIN 生成。动态输入降低时没有实时改变前馈斜坡，不能把其动态线电压前馈行为当作已验证。
- **器件与寄生：**已有单元模型只覆盖其声明部分。芯片内部延时、CS 噪声、饱和、QR/ZCD误触发和器件寄生必须看具体网表/探针；通用模型跑完不是原厂模型、实测或安规结论。
- **条件覆盖：**当前每次整网一个 Vin 端点；电压表支持声明的多次掉电恢复、分阶段负载支持重复复位，但不自动穷举多源独立电压组合、全部先后顺序、温度、容差或短路恢复。实际事件是否触发取决于该次电压与阈值，不能仅因事件表包含掉电就声称已验证热重启。
- **负载真实性：**分阶段 R/I/P 和多轨条件是可追溯的工程近似。没有从名称推断固件启动状态、I/O 反灌、上拉供电、机械负载或实测电流波形；不同电源引脚之间的动态关联由用户显式配置。默认阶段和例程功耗均不是用户板卡实测。
- **时间与数值：**网表从 t=0 以 `uic` 运行，关闭 RAW 压缩并保存指定探针；默认 Gear、相对容差 0.001。频率/最大步长限制用于约束数值实验，不保证全部开关边沿已被采样。预计 `stop_s/max_step_s` 超过 2500 万时拒绝导出；不能通过放宽最大步长绕过再宣称保护采样可靠。

`system_sequence_export.project_files(project)` 生成文件字节与实验清单；`export_project(project, folder)` 将其写入指定目录。`system_sequence_units.compile_unit` 将单元内置网表封装为有命名空间的子电路，移除独立输入源、EN、VCC 和原额定 BLOAD 夹具，避免多个电源互相污染全局库符号或重复加载负载。它不读取任意用户 SPICE 文件。

## 10. 分阶段完整例子：源保护、多轨复位与热重启

联合启停运行设置默认勾选“Buck/Boost 保留器件寄生电容”。只在本次电路快照中启用单元已填的常数 Coss、Qg/Vgs 等效栅电容和控制器设置中的 Cj，不改已保存单元的独立仿真设置。旧工程缺少此新字段时也使用该默认值；取消勾选才沿用原单元的边沿模式。清单记录原模式与实际采用模式。Cj若没有实测仍是模型假设，不能把启机验证当作真实开关损耗验证。

这是针对断续导通换流的模型修正：若所有开关节点电容为0，47µH电感在功率器件截止后仅经约0.83GΩ关断阻抗退流，形成约56fs的刚性时间常数。测试中等值电容的不同数字写法即可改变卡顿时刻，增大二极管转折也不能稳定解决。保留已声明寄生储能后，实际45ms对照完整完成、无求解警告，且没有放宽LTspice容差。不能通过改数字格式来冒充收敛修复。

通过画布“打开工程”载入 [SYSTEM_STAGED_STARTUP.json](../examples/SYSTEM_STAGED_STARTUP.json)。该文件由 [validate_sequence_realistic.py](../tools/validate_sequence_realistic.py) 从上一例程生成，保留 12V/5V Buck、3.3V LDO 的同一套硬件，不读取或改写用户当前画布。名称中的“真实限流”表示限流已参与电路求解，不表示源保护或控制板负载来自实测。

### 10.1 电源及供电依赖

供电结构仍为“24V 主源 → 12V Buck，与 12V 备用源二极管 OR → 5V Buck → 3.3V LDO”。主备源分别改成 **2A / 1A 的主动恒流模式**，默认同在 0–2 ms 上升；主源 27 ms 开始下降、28 ms 降完，主 Buck 在 29 ms 关闭 EN。备用源 38–39 ms 下降，5V Buck 和 LDO 在 41 ms 关闭 EN；正常例程观察到 45 ms。上述为试验输入时刻，实际 EN 仍受 UVLO/就绪条件限制，电压下降取决于储能与负载。

变换器仍沿用原例程的 LTC3864 参考通用模型、20mΩ 采样与 95mV 标称 CS 门限，以及明确简化的 TLV755P 参考 LDO。外部源的 2A/1A 与 Buck 的约 4.75A 开关采样峰值限制属于不同位置，不能直接互换。本例源参数、板卡阶段、就绪阈值和复位时刻均为**工程演示假设**，用于验证模型机制。

本例两源分别声明10µF / ESR 0.1Ω的输出电容，位于源限流/阻断后，四个工况使用相同值；没有删除原有变换器输入电容。这是未取得真实供电器数据时的工程假设，不能写成实测或用于校准实物。零源端电容的早期关机数值失败保留在诊断记录中，不以新增电容的结果冒充原零电容网表通过。

### 10.2 一个板卡用多个电源引脚负载描述

| 负载节点 / 供电端口 | 全部就绪条件（开启 / 关闭） | 连续就绪后延时 | 待机与额外电容 |
| --- | --- | --- | --- |
| `LOAD-3V3`：MCU / LDO 3.3V | 本地 3.05 / 2.75V，同时 5V 轨 4.65 / 4.35V | 0.5 ms | 待机 2mA；低压缩放沿用 3.3 节 |
| `LOAD-5V`：通信采样 / 5V Buck | 本地 4.65 / 4.35V，同时 3.3V 轨 3.05 / 2.75V | 1 ms | 待机 5mA；另声明 47µF 输入电容，不代替 Buck 已有 Cout |

这里相互等待的是**板卡运行负载**，不是让 5V 和 3.3V 两个电源互相等待才开机。电源仍按原例程依赖建立：5V 等待 OR，LDO 等待 5V。因此板卡可等两轨就绪后再释放，不会因上述负载条件本身阻止电源空载建立。也不保证不存在由源能力不足引起的掉压复位，需看实际仿真。

### 10.3 四个声明工况与应该核对的现象

开发验证工具为每个工况保存独立工程、运行目录和清单，校验各单元 `spec` 的硬件摘要相同。工况只改输入事件、外部供流能力及观察时间，不改变换器硬件来“跑过”。

| 工况 | 输入变动 | 应核对的证据，不能提前认定通过 |
| --- | --- | --- |
| `normal` | 上述 2A/1A 恒流、正常上电和主备依次关断，45 ms | 两源电流与限流有效状态；各轨 EN/90% 时刻；负载是否到最后阶段；OR 切换、电压跌落、关断残压 |
| `weak_hiccup` | 故障注入：主/备可用供流降至 40/30mA，连续限流 0.7 ms 后休眠 3 ms，观察 25 ms | 故障/重试是否实际进入，弱源是否阻止后级建立；这是有意的供流不足，不能作为正常源额定值，也不把“未启动”改成通过 |
| `warm_restart` | 两源 22 ms 开始跌落，22.5 ms 到 0，32 ms 开始恢复，34 ms 到正常电压；观察 60 ms，单元 EN 时间窗口延长至 65 ms | 输入掉电前全部负载已到最后运行阶段；掉电窗内实际掉压复位；恢复后从首阶段重新计时并再次到末阶段，保留再充电浪涌和残压 |
| `slow_input` | 两源从 2 ms 上升时间改为 8 ms，其余同正常工况 | UVLO/就绪时刻是否随实际电压推迟；初始化负载是否过早建立，是否引发限流或欠压反复 |

热重启表使用倍率点 `(0,0)、(2ms,1)、(22ms,1)、(22.5ms,0)、(32ms,0)、(34ms,1)、(60ms,1)`；最后保持正常电压，旧单次关断字段不再作用。若修改源额定电压，倍率仍相对本次所选 Vin 端点，不是固定写死 24V/12V。

初版18ms掉电的数值求解已完成且无警告，但驱动负载约18.755ms才进入末阶段，因此没有满足“全部负载运行后再断电”的试验前提。其失败验收保留；现把掉电移至22ms并重新仿真，不把命令掉电与电容放电后的真实复位时刻混为一谈，也不通过放松验收条件宣称初版通过。
