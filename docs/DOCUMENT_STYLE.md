# 项目文档写作与排版规范

本规范用于编写和修订说明、教程、工程报告与项目文档。版式样本为[《计算方法与公式说明》](reference/计算方法与公式说明.docx)。用户提供的模板和交付要求优先。

## 写法

- 标题直接写主题。开篇说明读者要解决的问题、讨论的对象和工况。术语首次出现时给出全称或一句定义，后文沿用同一称呼。
- 计算说明按物理过程组织。先定模型、测量节点和假设，再由方程推到结果，最后用一个可复算例说明怎样代入和检查。教程沿操作步骤展开，每步写清输入、动作和可观察结果。
- 工程评审先给关键结论和待复核项，随后列工况、方法、数据、证据及限制。模型计算、行为仿真、原厂模型和实测各自注明来源。未计算或未收敛的工况保留状态及原因。
- README 与短说明按实际使用顺序安排标题。内容短时可直接进入正文。历史验证记录保留当时的工况、结果和追溯标识。

## 公式与数据

- Word 公式使用可编辑的原生数学对象。长文的独立公式按章编号，正文通过编号引用。短文只给需要交叉引用的公式编号。
- 公式附近定义首次出现或含义改变的符号、下标和单位。涉及方向或电压时写清参考方向、节点及测量位置。涉及时间量时说明窗口和时间原点。明确平均值、有效值、峰值及峰峰值的区别。无量纲量注明无量纲。
- 图表有说明其用途的标题。图题在下，表题在上。图轴和表头标单位，表头跨页重复。同一列使用一致单位和合理的有效位数。输入端点不同时并列比较，重合时合并重复结果。
- 引用给出来源名称及可定位的章节、图表或链接。厂商规格、软件采用的假设和冻结算例分别写明。复算旧结果前核对配置、模型版本和测量节点。

## 版式

| 对象 | 默认设置 |
| --- | --- |
| 长篇 Word 手册与教程 | A4。中文正文宋体，拉丁正文 Cambria，章标题用无衬线中文字体。正文约 11 pt，公式使用 Cambria Math 或兼容数学字体。使用清晰的章、节层级、页码及可跳转目录。 |
| Word 工程报告 | 沿用相同字体与颜色。先列评审结论，再以可跳转目录索引后续章节。章内编排图、表和公式。正文自然分页，双端点的宽表或波形可用横向 A4。表头跨页重复。状态用清楚的文字，颜色辅助区分。 |
| 短篇说明 | 标题下直接进入内容，分页随正文。 |
| Markdown、HTML 和其他格式 | 沿用术语、标题层级、证据顺序与符号约定。使用对应格式的导航、数学公式、表格及图注。 |

桌面和本地 Python 网页的 Word 报告共用 `docx_layout.py`。独立浏览器内核的 Word 版式由 `web_app/frontend/src/native_engine/reports.ts` 维护。计算说明、教程和自动计算依据共用书籍样式，入口见 `docs/calculation_reference_layout.py` 和 `docs/apply_book_style_to_help.py`。更新内置帮助文档时，同步生成入口，核对应用打开的资源和交付版本。交付前查看实际渲染，检查目录跳转、公式、图表和跨页位置。
