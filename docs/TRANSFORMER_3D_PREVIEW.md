# 变压器三维结构预览

三维预览用于检查磁芯、绕组和层序的位置关系。在单元设计的“磁件”页点击 **3D 结构预览**，打开独立窗口。设计界面保持可操作；已打开的预览随绕制参数更新，不启动电磁或电路求解。

## 1. 从工程生成结构

先完成一次有效的变压器计算，再在“变压器可绕制评估”中填写骨架净窗口尺寸。预览读取同一次计算确定的整数匝数、线径、股数和并绕根数，并复用二维绕制评估的每个线束截面。交错层序、层间绝缘和手动移动的逐匝位置均保留。

三维建模设置中的轴向基准和绕线路径优先使用。缺少路径时，程序按可用的中柱外形与所标注的骨架壁厚假设估算。绕组平均匝长和 DCR 使用对应路径，结果标明其来源。

结构或电气参数变化后，预览提示结果待更新。绕制位置编辑完成后重算线长。透明度和相机视角只控制预览显示。

## 2. 查看与操作

| 操作 | 显示效果 |
| --- | --- |
| 左键拖动 | 围绕结构旋转视角 |
| 滚轮 | 放大或缩小 |
| 右键拖动 | 平移视角 |
| 立体、正视、俯视、侧视 | 立体采用透视；三视图采用正交投影，可直接比较轮廓 |
| 完整、上半芯、下半芯 | 单独查看半芯的底轭、外柱、窗口和中柱 |
| 复位视角 | 重新完整显示当前结构 |
| 自动旋转 | 持续转动；关闭后停止 |
| 磁芯不透明度 | 调整半透明磁芯；低不透明度便于看清内部深色绕组 |
| 绕组与物理层 | 单独显示或隐藏某层，检查交错关系 |
| 分解装配 | 分开磁芯和绕组以便观察；分解状态不代表真实尺寸位置 |
| 导出当前视图 | 保存当前视角的 PNG 图片 |

模型库浏览只切换查看的磁芯，不修改工程选型。选择其他磁芯时暂不叠加当前工程绕组，点击“返回当前工程装配”恢复。

## 3. 尺寸和轨迹的含义

计算和工程文件保存 SI 单位；三维预览边界统一换成毫米。绕组轴为 Z 轴，磁芯合模面中心为三维坐标原点。

| 参数 | 定义 |
| --- | --- |
| 轴向局部坐标 u | 从骨架净窗口起点到某匝截面中心的距离 |
| 径向局部坐标 v | 从骨架内侧路径向外到某匝截面中心的距离 |
| z0 | 净窗口起点相对合模面的 Z 坐标；截面轴向位置为 z0 + u |
| r0 | 圆形绕线路径的内侧半径；线束中心半径为 r0 + v |
| 线束宽度、高度 | 二维截面的轴向和径向尺寸；利兹线压扁后的尺寸沿用绕制配置 |
| 物理段 ID | 稳定的绕制层标识；层的绕组归属由 winding_id 决定，不从 ID 的文字猜测 |

串联绕组按段连接顺序连续绘制。首层由窗口下端向上绕。相邻的下一层在同一端直接换层，轴向推进方向随之反转。若中间隔着其他绕组，导线从当前层末端沿轴向折返至骨架下端，在窗口边缘向外过渡，再从下一层下端继续绕制。折返段上方的绕组显示局部隆起，便于检查引线所在周向位置与窗口余量。

接线优先读取各段的起止节点、绕向及端口声明。缺少接线数据的旧工程按同一绕组的物理层序显示工艺示意。明确的并联支路、带抽头或端点有冲突的层保持独立。中间节点若有独立声明的引线路径，预览沿该路径连接。未填写实际引线路径时，端部弯曲和局部隆起为工艺估算。利兹线按成品线束显示，并绕线各自保持连续。

查看跨线时可将磁芯透明度调低或选择“绕组”。装配视图中两端均可见时显示跨线。分解装配时暂时隐藏跨线，以便单独检查各层。各匝尺寸和放置位置以工程数据为准，跨线及由此产生的抬高只参与预览。

只有三维建模设置中明确声明的物理气隙参与几何显示。电气计算得到的等效气隙在说明中列出，不能直接等同于每个磁柱的加工间隙。绕组超出窗口时保持原尺寸并提示，不通过缩小线径使图形看似可装配。

## 4. 磁芯模型和来源

电气磁芯库与机械模型库分别维护。有效截面积 Ae、有效体积 Ve 和平均每匝长 MLT 不能唯一确定实体外形；三维模型从原厂规格书机械尺寸建立。模型条目记录厂家、参考型号、资料链接、页码、名义尺寸以及未建模的细节。

软件原有简写型号可能对应多种厂家规格。预览显示所采用的参考版本；更换为真实供应商的磁芯时应核对该版本。倒角、夹具和细小工艺槽按模型条目的说明处理。缺少完整机械尺寸的条目明确列为待补，不由电气参数生成猜测的实体。

相关数据位于 `resources/core_shapes/`。`catalog.json` 保存机械尺寸及来源，可在缺少工程路径时用于匝长估算。`meshes/` 保存三角网格和索引，仅用于三维渲染。磁芯电气有效面积、体积及材料仍由电气磁芯库提供。

PQ32/30 使用 TDK 对应型号三视图建立收腰底轭、圆弧外柱、圆中柱和两侧开口。其他 PQ 型号分别使用自己的图纸，不按一个外形整体缩放。RM 保留原厂的三类轮廓；EP 保留单侧槽和圆形后腔；EFD 使用逐型号的扁柱、偏置台阶及引线缺口。未标尺寸的局部圆角或曲线跟随原图示意，并在来源说明中列出。

当前覆盖全部 67 个内置型号：58 个按指定厂家规格书主要尺寸建模，8 个短型号明确采用列出的厂家参考版本，T58x37x20 按型号的 58×37×20 mm 名义尺寸建模，待补确切原厂料号。逐项来源和版本说明见 [磁芯机械参考目录](../resources/core_shapes/README.md)。

## 5. 与联合仿真的关系

预览是工程几何的可视化。电磁仿真继续使用已配置的 CAD、网格和材料参数，提取自感 L、互感 M 和耦合系数 k；联合流程再按选定裕量回填计算输入并运行电路仿真。旋转、隐藏和分解装配不会修改这些输入或结果。

## 6. 运行环境

桌面版使用本地 WebGL 预览窗口。Three.js、界面资源、尺寸目录和全部 67 个型号的三维网格随程序提供，运行时不从互联网加载资源。Windows 需要 Microsoft Edge WebView2 Runtime；缺少时会显示安装提示。无需安装 Blender，也无需手动启动浏览器或命令行。复制便携版时保留完整 `_internal` 目录。

本次入口属于个人桌面版。Python 网页和独立 TypeScript 计算路径的原有功能保持各自范围；不把桌面预览的接入视为其他客户端已完成相同入口。
