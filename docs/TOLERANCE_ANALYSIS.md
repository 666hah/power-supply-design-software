# 硬件容差边界与分布评估

在桌面电源单元打开「⑪ 硬件容差边界与分布评估」。先核对各路输出规格和器件容差，再点击页面上方的「计算极限容差」。结果发现超限后，「运行蒙特卡洛」按钮可用。工程 JSON 保存规格、容差和运行设置。也可单独导入或保存容差配置，导出 CSV、详细 JSON，或随 Word 和 Excel 设计报告保存本次有效结果。

添加或编辑器件容差时，用「输入单位」为下限、上限和标准差 σ 选择共同单位。程序随单位切换换算标称值和已填写的数值。例如，电感上限 `44 µH` 切换到 `mH` 后显示为 `0.044 mH`。无量纲倍率按原数值填写。保存配置时统一换算成 SI 基本单位。

## 先检查极限容差

程序冻结标称选型、绕组匝数和补偿。支持公式推导的子模型先直接求边界，再从标称、器件偏差、输入端点和轻重负载中安排少量整机候选工况。相同器件值与工况合并计算。桌面入口按该方法执行，数值分析接口保留原有计算模式。

### 反馈分压的理论边界

对于已识别的运放或 TL431 分压网络，稳压取样端的静态设定值为

\[
V_{\mathrm{set}}=V_{\mathrm{ref}}\left(1+\frac{R_{\mathrm{up}}}{R_{\mathrm{down}}}\right).
\]

其中 \(V_{\mathrm{ref}}\) 为基准电压，\(R_{\mathrm{up}}\) 为取样端到分压点的电阻，\(R_{\mathrm{down}}\) 为分压点到参考地的电阻。基准和电阻为正值。提高 \(R_{\mathrm{up}}\) 或降低 \(R_{\mathrm{down}}\) 会提高设定值，因此上限直接代入上臂上偏、下臂下偏，下限取相反组合。结果列出两个组合和对应电压。防反压降、整机纹波和阶跃包络由对应功率级复算。

### 单相 Buck 的纯电容纹波边界

固定输出电压 \(V_o\) 和开关频率 \(f_{\mathrm{sw}}\)，理想连续导通下有

\[
\Delta V_{C,\mathrm{pp}}=\frac{V_o(1-V_o/V_{\mathrm{in}})}{8 L C_\Sigma f_{\mathrm{sw}}^2}.
\]

\(V_{\mathrm{in}}\) 为输入电压，\(L\) 为输出电感，\(C_\Sigma\) 为并联支路的总电容。高线、电感低偏和电容量低偏使纯电容纹波最大。仅在该极端组合下额定负载仍满足理想连续导通条件时列出计算边界。最终端口纹波考虑器件压降、ESR 和 ESL，由整机计算提供。[Analog Devices Buck 功率级计算](https://www.analog.com/en/resources/app-notes/buck-power-stage-design-equations.html)

### 整机候选工况

器件应力、纹波与环路分别参考相关参数的作用方向选组合。单相 Buck 还检查输入区间内部的电容纹波候选。连续导通、三角形电感纹波模型下，输入电容组纹波有效值的平方为 \(I_o^2D(1-D)+D\Delta I_L^2/12\)。\(I_o\) 为平均负载电流，\(D\) 为占空比，\(\Delta I_L\) 为电感电流峰峰值。忽略 \(\Delta I_L\) 时，最大值在 \(D=0.5\)。考虑电感纹波随占空比变化时，用该表达式的驻点或导通模式分界生成候选，再用完整模型复算。实际峰值位置仍受器件和工作点影响。[TI Buck 输入电容计算](https://www.ti.com/lit/an/slyt670/slyt670.pdf)

整机通常最多用七组器件值。标称组先查输入端点、声明负载和代表性错载。偏差组复算筛选出的高低线与轻重负载。单相 Buck 在有足够连续导通结果时还可根据三点实际纹波最多追加一次邻点复算。每项显示已算最不利值、限值、余量、工况、器件偏差和选择依据。未发现超限时，整机仍标为区间边界待复核。相位裕度、动态响应及包括 QR 换谷在内的模式变化均按实际选中的工况报告。

### 检查指标

- 器件规格读取 BOM、磁件和现有计算快照中的限值，包括半导体应力、每颗电容耐压与纹波电流、电阻功耗和磁件磁密及温升。缺少规格或模型结果时标出待补。
- 各路输出电压使用端口电压的下限与上限，含现有模型覆盖的稳态纹波和负载阶跃包络。防反后的端口是判定点。反相输出采用有符号电压。规格需按产品填写。
- `Vpp_ripple` 是当前稳态纹波模型给出的电压峰峰值，默认从当前需求的纹波目标换算成伏。
- `Vpp_transient` 是 10%→90%→10% 双向负载响应的峰峰值。可以建立多路闭环模型时，还检查各路单独和同时变化。个别拓扑仅提供主反馈路负载响应，其他路标出缺少动态覆盖。使用当前工作点的低频线性模型，启动和保护仍由对应验证任务检查。限值需按产品填写。
- 相位裕度取当前环路模型在 0 dB 穿越点中的最小值，严格大于 45° 时满足，等于 45° 时超限。缺少有效相位裕度时待复核。补偿自动整定沿用工程所设的目标。

### 算例预填

算例中已建模的电容容值为 ±10%，独立电阻为 ±1%，变压器励磁电感或采用的磁场自感矩阵整体倍率为 ±5%。上下限分别取标称中心的 ±3σ，截断前标准差等于公差半宽除以 3。额定匝比和矩阵耦合系数保持物理定义。电容 ESR、ESL、MOS 导通电阻及未建模的器件参数可按资料单独配置。已有实测或厂家分布时可编辑该项，并记录来源。

软件能从已选普通运放或 TL431 网络识别反馈分压时，固定参考电压，以分压电阻实际偏差更新取样端的稳压设定，再按原功率级计算输出防反后的端口电压。其他控制模式沿用其现有取样和稳压模型。

## 发现超限后估计概率

- 发现超限后，设置样本数和随机种子，再点击「运行蒙特卡洛」。抽样沿用本轮冻结的标称硬件与补偿，每个样本按蒙特卡洛的输入及负载工况网格计算。修改样本数、随机种子或计算上限后可直接重跑抽样。修改设计、规格、容差或负载工况后应重新计算极限容差。
- 候选工况未见超限时，蒙特卡洛按钮保持禁用，结果仍显示区间覆盖和待补证据。已有指标超限时可以抽样，缺少可用分布或预算不足时会显示抽样状态。
- 每个统计样本代表一块虚拟硬件，同一组器件值计算完整的输入及负载工况。任一器件指标超限计作器件事件，任一外特性指标超限计作外特性事件。默认各行独立，同一相关组共享随机分位。两类事件分别汇总，证据不足的样本另计待判定并给出观测比例范围。
- 显示已比较单位的超限计数。证据完整时给出样本概率及精确二项 95% 区间；零次超限另报单侧 95% 上限。样本均值 μ 与标准差 s 的 μ±4s 是描述性统计；只有经验分位所需尾部样本充分时才显示 4σ 等效分位。常用样本数的零超限仍有统计不确定性。[NIST 精确二项区间](https://itl.nist.gov/div898/handbook/prc/section2/prc241.htm)
