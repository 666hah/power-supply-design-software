# 最坏工况与容差

在桌面版打开 **工程评审 → 最坏工况与容差**。选定输入和负载工况，添加需要分析的标称参数，然后填写绝对上下限。界面按行注明单位。可将配置另存 JSON 并在同一设计重新载入。计算结果可导出 CSV 或 JSON。当前工程结果也进入独立 Word 和 Excel 设计报告。

## 规格边界

软件在最低输入的标称设计上冻结磁芯、绕组、型号及补偿。随后对选中容差的上下限组合逐一复算，并在输入低端、中点和高端检查所选负载。相同输入自动合并，有不同手动开关事件时保留两个具名点。可按各路同比额定负载扫描，也可声明各路分别取值的负载组合。零负载需另按对应控制器的停脉冲模型验证。

可扫字段随拓扑显示，包括功率电感或励磁电感、导通电阻、采样电阻、相应的钳位电容、整流压降、变压器等效热阻和逐颗电容的 C、ESR、ESL。采用独立场解自感矩阵时，励磁电感由矩阵拥有，界面不再用标量冒充其公差。

表内每个指标给出限值、最不利值、余量、输入、负载及实际参数组合。有动态限值的指标按该工况的余量排序。正余量表示在所列检查条件内，负余量表示超限。缺失的工况、环路或限值单独标记。离散角点可能遗漏区间内部的极值。模式切换、故障、启动、温度迭代及器件曲线之外的现象仍应独立验证。

## 蒙特卡洛与 4σ

- 只有上下限时可选“仅规格边界”。蒙特卡洛需为每个已选参数声明均匀、三角或截断正态分布，并保存依据。三角分布以当前标称值为众数。截断正态的标称值和 σ 分别是截断前的中心和标准差。只有在资料明确将对称规格定义为 ±4σ 时，才可用规格半宽除以 4 换算 σ。
- 每次抽样生成一块虚拟硬件。用同一组器件值走完各个输入和负载条件，取该指标在整组工况的最大值或最小值，再对虚拟硬件总体汇总。默认各行独立，同一相关组共享随机分位，可表示同向变化。规格边界仍独立遍历各行上下限。
- 统计表提供均值 μ、样本标准差 s、常用分位和描述性的 μ±4s。正态的 ±4σ 约对应两侧合计 99.9937% 覆盖。非线性换谷、限流或偏态结果可能使实际尾部分位和 μ±4s 不同。经验 4σ 分位只在两侧各有至少约 20 个预期尾部观测且数据完整时显示。常规样本量下可看分布趋势，尾部保持“样本不足”。

## 依据与复核

- [TI SLUP308，第 1 节](https://www.ti.com/lit/ml/slup308/slup308.pdf) 给出工作边界与最坏情况校核项目。
- [TI SLVA481](https://www.ti.com/lit/an/slva481/slva481.pdf) 给出按参数分析敏感度的方法。
- [JCGM 101:2008，第 7.2 节](https://www.bipm.org/en/doi/10.59161/jcgm101-2008) 说明蒙特卡洛传播及尾部分位对样本量的要求。表内有效样本数按虚拟硬件计。当前项目的尾部筛选阈值是报告约定。
