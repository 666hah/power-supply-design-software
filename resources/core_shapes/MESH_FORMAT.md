# 内置磁芯网格

`meshes/index.json` 是内置模型目录，每个型号对应一份独立的 `.json.gz` 三角网格。应用在本机读取当前型号，将解压后的数据传给预览窗口；离线使用不需要下载、Node.js 或访问其他项目。切换库中型号时仅按型号名读取，页面不能指定文件路径。

## 单位与部件

网格采用 `power-core-mesh.v1`，长度单位为 mm。几何状态 `nominal_ungapped` 表示标称未磨隙装配。每个部件包含：

| 字段 | 含义 |
| --- | --- |
| `id`、`name` | 部件稳定标识和显示名称 |
| `half` | 下半芯为 −1，上半芯为 1，整体磁环为 0 |
| `role` | `center` 中柱、`return` 外柱、`yoke` 底轭、`body` 整体磁芯 |
| `position_mm` | 部件局部原点相对于磁芯坐标原点的位置 |
| `positions` | 按 x、y、z 排列的局部顶点坐标 |
| `normals` | 与顶点一一对应的局部法向量 |
| `indices` | 每三个索引组成一个三角面 |
| `bounds_mm` | 所有部件平移后组成的磁芯包络 |

分解和隐藏半芯在显示阶段执行。工程明确声明中柱磨隙时，仅缩短相应中柱；垫片气隙平移两半磁芯。电气估算的等效气隙不自动变为物理开隙。

## 来源与校验

目录保存规格目录文件 SHA-256、几何生成器 SHA-256，以及各型号完整记录的指纹。每份压缩文件同时保存压缩前后字节数、SHA-256 和网格统计。读取时校验这些信息，并检查有限坐标、三角面索引、部件角色、解压大小和目录边界。缓存最多保留八个型号，返回的数据副本互不影响。

三角面有效、包络一致只说明资源完整。外形是否符合图纸还须检查平面轮廓、开口、柱截面及三投影视图；厂家、图号、采样方法和未标注尺寸的处理见 `catalog.json` 的 `shape_evidence`。

## 开发时重建

更新规格目录或 `resources/transformer_preview/core_geometry.js` 后，运行 `tools/build_core_meshes.py` 重新生成全库。生成器只在开发环境运行，先验证全部网格，再写入压缩文件，最后更新索引。发布时保留整个 `resources/core_shapes` 目录；目录和网格必须来自同一次生成。

原始厂家 PDF 位于开发过程的 artifacts 目录，不随程序分发。软件内置的是独立网格、轮廓数据和来源说明，电磁提取仍读取联合仿真配置的 CAD 与网格。
